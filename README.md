# Greenden

Greenden is a simple multi-page plant and flower storefront built with HTML and Tailwind CSS 2.2.19. Tailwind is loaded from its CDN stylesheet, and the pages use responsive utility classes for layout and styling.

## Pages

- `index.html` - Home page with an introduction, store highlights, best sellers, customer reviews, and newsletter section.
- `product.html` - Product gallery with plant images and a search field. The search field is visual only.
- `contact.html` - Contact form layout. The form is not connected to a backend.

## Run Locally

No build step or package installation is required. Open `index.html` in a browser, then use the navigation links to visit the other pages. The Tailwind CDN link requires an internet connection.
